Build a complete, production-quality ADMIN CONTROL PORTAL for the
"LearnPath AI" personalized learning platform.

IMPORTANT:
This is a FRONTEND-ONLY implementation.

Do NOT implement:
- Backend
- MongoDB
- FastAPI
- Real authentication
- Real AI
- Real external APIs
- Real YouTube integration
- Real GitHub integration
- Real recommendation engine

Use realistic mock data and frontend state.

The Admin Portal must be designed so that a future FastAPI + MongoDB backend can connect to it without redesigning the frontend.

============================================================
1. CORE ADMIN CONCEPT
============================================================

There must be ONE CENTRAL ADMIN PORTAL.

The admin portal is the central control plane of the entire
LearnPath AI platform.

The administrator should be responsible for essentially every
configurable function of the platform.

The Admin Portal should NOT be treated as a normal analytics dashboard.

It should function as:

- System Control Center
- User Management System
- Learning Content Management System
- Skill Management System
- Assessment Management System
- Recommendation Management System
- Learning Path Management System
- AI Configuration Center
- External Resource Management System
- Platform Analytics Center
- Moderation Center
- Notification Center
- System Settings Center
- Audit and Activity Center

The administrator should be able to inspect, configure, enable,
disable, edit, approve, reject, publish, unpublish, reorder,
override, and monitor platform functionality.

============================================================
2. ADMIN ACCESS
============================================================

There should be a completely separate admin login.

Route:

/admin/login

The admin portal must NOT be accessible through the normal learner
registration system.

There should be:

/login

for learners.

And:

/admin/login

for administrators.

IMPORTANT:

There must be NO public "Create Admin Account" button.

Administrators cannot register themselves from the frontend.

The UI should clearly communicate:

"Administrator access is restricted."

Admin login fields:

- Email
- Password
- Remember Me

Buttons:
